2. AEON operator — capture a pre-switch backup, then reconcile the frozen
   classic PPM through its read-only API. Supply these values in the approved
   operator shell; never print a key or resolved environment:

     : "${AEON_DATABASE_URL:?approved AEON database URL required}"
     : "${CLASSIC_PPM_URL:?approved read-only classic API URL required}"
     : "${CLASSIC_PPM_KEY_FILE:?approved classic API key file required}"
     : "${AEON_TENANT:?approved AEON PPM tenant slug required}"
     : "${AEON_BIN:?pinned AEON binary path required}"
     : "${EVIDENCE_DIR:?private approved evidence directory required}"
     test -f "$CLASSIC_PPM_KEY_FILE"
     test -x "$AEON_BIN"
     pg_dump --format=custom --file="$EVIDENCE_DIR/aeon-before.dump" "$AEON_DATABASE_URL"
     "$AEON_BIN" import reconcile --source-url "$CLASSIC_PPM_URL" --api-key-file "$CLASSIC_PPM_KEY_FILE" --tenant "$AEON_TENANT" > "$EVIDENCE_DIR/reconcile-before.json"
     "$AEON_BIN" import paimos --source-url "$CLASSIC_PPM_URL" --api-key-file "$CLASSIC_PPM_KEY_FILE" --tenant "$AEON_TENANT" --delta > "$EVIDENCE_DIR/delta.json"
     jq -e '(.conflicts|length)==0 and (.skipped|length)==0' "$EVIDENCE_DIR/delta.json"
     "$AEON_BIN" import paimos-attachments --source-url "$CLASSIC_PPM_URL" --api-key-file "$CLASSIC_PPM_KEY_FILE" --tenant "$AEON_TENANT" > "$EVIDENCE_DIR/attachments.json"
     "$AEON_BIN" import backfill-relations --tenant "$AEON_TENANT" > "$EVIDENCE_DIR/relations.json"
     "$AEON_BIN" import reconcile --source-url "$CLASSIC_PPM_URL" --api-key-file "$CLASSIC_PPM_KEY_FILE" --tenant "$AEON_TENANT" > "$EVIDENCE_DIR/reconcile-after.json"
     jq -e '.partial==false and .skipped_count==0 and ([.projects[].categories[] | (.missing|length)+(.extra|length)+(.changed|length)] | add // 0)==0' "$EVIDENCE_DIR/reconcile-after.json"

   Compare project/kind/state counts, comments, relations, knowledge, person
   links and attachment count/bytes/hash samples with the frozen source.
   Resolve conflicts, skipped records or attachment failures, rerun the delta
   and reconcile, and keep the source frozen. Zero unexplained differences is
   the gate. Never overwrite an AEON-side edit simply to force zero.
